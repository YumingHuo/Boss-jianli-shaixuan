# Boss简历删选工具

插件名称：识才 · BOSS 内部招聘助手。Manifest V3 Chrome 扩展，使用 TypeScript + Vite。当前为内部开发版，尚未发布到 Chrome 应用商店。

## 从源码安装

使用 Node.js 20.19+ 或 22.12+，在项目目录执行：

```bash
npm ci
npm run check
```

检查通过后会生成 `dist` 目录。在 `chrome://extensions` 打开“开发者模式”，点击“加载已解压的扩展程序”，选择 `dist`。每位使用者需要自行配置招聘岗位和模型接口；仓库不包含 API Key、BOSS 登录状态或真实候选人记录。收到已构建安装包的同事可参照[安装说明](docs/安装说明.txt)。

当前版本为 0.1.9。源码测试和构建通过不代表真实模型分析已完成验收，具体限制见下文。

## 0.1.9 内容不足时自动跳过

- 在线简历已读到底、身份与识别清晰度均通过核对，但正文不足以分析时，记录为“已跳过 · 内容不足”。自动读取关闭该份简历后继续下一位，分别统计成功读取和跳过数量。
- 跳过状态保留在候选人池，刷新、普通页面扫描和重复记录合并不会清掉此状态，也不会重复自动读取；候选人、收藏和跟进状态保留。仍可在 BOSS 页面点击“读取当前简历”，取得有效正文后恢复分析流程。
- 内容不足不产生模型任务，不计入模型异常，也不将候选人标记为淘汰。图片未加载完整、识别不清晰、身份变化及页面验证仍明确停止，不能作为内容不足自动略过。
- 版本验收：123 项自动化测试、TypeScript 检查及生产构建通过，包含跳过后读取下一位、纯文字短简历、跳过状态持久化、手动重读恢复及其他错误不能误跳过。Chrome 原生扩展管理已重新加载并核实 0.1.9；已切回原有 BOSS 标签页，未刷新或关闭页面。刷新后才会使用新版页面脚本；未主动启动模型调用或真实批量读取，实际自动跳过仍待现场验收。

## 0.1.8 小窗口与完整简历读取

- 按原图清晰度保存当前段的正文图片；相邻段保留重叠，页面替换画布后先前片段仍可识别。合并时只删除相邻片段中有充分相同正文依据的重叠，不全局删除重复的公司、职位等文字。仅在本机识别图片。

- 显示加载段数、到达底部和图片识别进度；底部图片加载失败、滚动受阻、正文被裁切或超过本机处理容量时明确停止。切换候选人、关闭简历、页面切到后台或点击停止时不写入未完成的识别结果；不截取超长简历提交评分。
- 版本验收：114 项自动化测试、TypeScript 检查和生产构建通过，覆盖 200 像素高窗口、滚动后增加教育图片、画布替换、外层弹窗滚动、正文空白、加载失败、候选人切换、图文裁切及重叠去重。已通过 Chrome 原生扩展管理重新加载并核实 0.1.8；原有 BOSS 标签页保留，已切回该页，尚未刷新，刷新后才会使用新版页面脚本。

## 0.1.7 重复候选人修正

- 修复旧版使用含未读数、时间和最后消息的整段文字生成指纹而重复建档的问题。有稳定编号时仍优先使用页面编号；否则使用姓名、明确岗位与个人上传头像地址组合生成指纹，排除图片尺寸参数。没有可靠头像时去掉时间和未读数；头像晚加载时保留同一条目的已有键。
- 自动核对并合并旧记录：同一岗位和姓名，还需相同个人头像、相同完整简历或足够长且完全相同的非通用自述。不同稳定编号、不同头像、不同学校学历或跟进状态冲突不合并，不能只凭同名或通用招呼认定同一个人。
- 合并记录仍保留在本机，主记录展示学校、头像、简历、收藏和分析历史；旧页面编号、收藏操作和报告链接会转向主记录。统计显示合并后人数及合并记录数。
- 合并时暂停模型队列；重复等待任务取消，旧异常不会自动重试。相同岗位、材料与模型只保留一个可执行任务，原始任务历史保留，防止改键后重复调用模型。
- 版本验收：101 项自动化测试与构建通过；已通过 Chrome 原生扩展管理更新到 0.1.7，BOSS 页面核实同一版本，现场显示 327 名候选人、已合并 108 条重复记录。身份依据不足的记录保留，不只凭姓名合并；原始材料和任务历史仍在本机。本次未主动发起付费模型测试或批量重试。

## 0.1.6 模型等待与完整简历读取修正

- Qwen3.8 Max / Flash 请求默认发送 `enable_thinking: false`，对应模型的日期版本同样适用；其他模型保留原有请求参数。[千问官方参数说明](https://help.aliyun.com/zh/model-studio/deep-thinking)。
- 模型请求时限由 25 秒调整为 2 分钟；只在实际请求进行期间调用扩展 API 维持后台存活，请求完成、失败或取消后清理计时器。超时保留为手动重试，现有异常任务不会因更新自动重发。[Chrome 后台生命周期说明](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)。
- 自动读取通过条目中的姓名进入聊天，避免误触头像入口；当前聊天已唯一核对时，兼容列表岗位未单独提取、姓名尾点以及未读状态导致的指纹变化。等待失败分别说明聊天核对、简历入口、正文加载或关闭失败。
- 图片简历由只取面积最大的一张改为按文档顺序读取全部正文图片和可见文字，保留矮幅教育图片与章节标题；长图分段识别，排除头像及隐藏容器。在正常的“查看全部 / 展开全部”按钮存在时展开，等待图片稳定后读取。
- 图片与文字混合的简历不再仅凭可见标题提前当作完整正文。OCR 完成前后核对同一候选人、简历文档与全部图片，继续保留清晰度和章节验证；不会把招呼或顶部简介当作完整简历评分。手动重读清除旧批量失败提示。
- 版本验收：90 项测试与构建通过；已通过 Chrome 原生扩展管理更新到 0.1.6，并在 BOSS 页面核实版本。调试标签页出现异常关闭后已停止浏览器接管，改用原生窗口操作并恢复了 BOSS 沟通页。后续用户在 0.1.7 使用中确认在线简历的打开、识别和关闭正常；这不代表模型分析已通过，用户仍反馈 12 项分析异常，具体服务商或解析错误待核实。本次未发起模型调用或批量重试。

## 0.1.4 候选人头像与分析错误诊断

- 从候选人卡片已经展示的图片读取 BOSS 头像地址，在工作台列表和详情显示；懒加载图片更新后补齐到原记录，不改变候选人身份或重复评分。图片地址仅允许 BOSS 域名的 HTTPS URL，失效时回退姓名首字。
- 此版保存头像地址，显示时从 BOSS 图片站加载，不提供离线图片归档。头像不会加入模型分析请求。
- 当前异常统计仅包含当前岗位、JD、简历版本、模型和接口对应的任务。换模型或接口前的失败保留在历史，不再混入当前异常数。
- 候选人详情增加模型请求状态及错误记录；后续 HTTP 错误保留经过脱敏的服务商说明与请求标识，方便区分模型名称、接口路径、权限、限流和参数兼容问题。已有旧错误无法还原当时未保存的服务商响应。
- 69 项自动化测试通过；头像真实页面显示、新模型配置及真实错误原因尚未核实。现有请求超时仍为 25 秒，未在没有真实错误证据时调整或发起付费测试。

## 安装开发版

1. Chrome 地址栏输入 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目的 `dist` 目录。
4. 刷新 BOSS 页面。点击 Chrome 扩展图标中的“识才”，打开工作台。
5. 新建招聘岗位，填写真实 JD，将 BOSS 显示的完整岗位名加入别名。
6. 首先只开启“页面扫描”，验证少量候选人的身份、岗位和文本是否准确，不配置或调用模型。
7. 配置公司批准的模型接口、Key、模型 ID，并授权资料发送。先确认候选人详情里读到了在线简历正文，再点击“继续分析”。图片简历尚未识别时不会进入队列。

**当前已验证用户沟通列表中的 160 条记录及岗位恢复，其他布局和详情页仍需单独验证。请先核对读取文本，再开始付费分析。**

## 使用边界

- 沟通列表摘要不等于完整简历；聊天列表中的最后一条消息也可能由招聘人员发送，适配时必须区分方向，不能直接视为候选人自述。
- 页面不展示的材料不获取；不读取内部接口、Cookie、框架隐藏状态，不自动登录、发送消息或绕过验证码。自动读取须由用户点击启动，只操作正常的候选人和在线简历入口。
- `src/content/parser.ts` 集中保存待验证的选择器。只有稳定身份才能可靠去重；指纹身份在内容改变后可能产生重复。
- 缺失的学历和未知学校不推断。内置院校库是基础库，不是全国普通本科和专科完整库；历史工程、校名更名及独立学院应核实。
- 独立筛选结果不改写 AI 分数。折叠策略只折叠插件的 AI 说明，保持 BOSS 原卡片布局。
- 暂停不撤销已发出的请求；取消和超时也不能撤销上游计费。后台中断的在途请求标记为“需手动重试”，防止静默重复扣费。
- 输出仅供人工复核。候选人材料中的指令视为不可信文本；模型不根据与岗位无关的敏感信息评分。
- 发送前移除常见姓名、手机号、邮箱、证件号码和部分无关字段；自由文本脱敏不能保证完全。可在候选人详情预览发送文本。
- 默认保存 30 天，可设置 1–365 天，收藏也受期限约束。到期以最近一次读取时间计算；浏览器启动或定时清理时执行。已导出的 PDF 不受本地自动清理约束。
- 报告使用 Chrome 原生打印“另存为 PDF”，不依赖远程 PDF 服务。原始简历下载使用 BOSS 本身的正常入口。
- 未实现多人账号、共享后端、跨岗位推荐、自动淘汰或自动联系候选人。

## 开发

```bash
npm install
npm run test
npm run build
npm run dev
```

`npm run build` 生成 `dist`。每次更新后，在 Chrome 扩展管理页点“重新加载”，再刷新 BOSS 页面。

`http://127.0.0.1:5173/?demo=1` 提供独立虚构数据的界面预览，与真实扩展的数据存储分离，不调用模型。
