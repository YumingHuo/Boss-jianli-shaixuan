识才 · BOSS 招聘助手 v0.1.9｜同事安装说明

这是当前开发版，供公司内部试用。安装不需要 Node.js、终端或其他开发工具。

一、安装
1. 解压收到的 ZIP，找到里面的 shicai-extension 文件夹。
2. 将 shicai-extension 放到电脑的固定位置，例如“文档”文件夹。安装后请保留该文件夹，不要移动或删除。
3. 在 Chrome 地址栏输入 chrome://extensions 并回车。
4. 打开右上角“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择 shicai-extension 文件夹。
   选中的文件夹里应直接有 manifest.json、background.js、content.js、ocr 等文件。
6. 扩展列表中出现“识才 · BOSS 招聘助手”，版本为 0.1.9，即完成安装。
7. 点击 Chrome 右上角的拼图按钮，可将“识才”固定到工具栏。

不要直接双击 index.html，也不要把 ZIP 当作安装程序运行。
需要 Chrome 120 或更新版本；如果公司的浏览器禁用了开发者模式，请联系公司 IT 处理安装权限。

二、第一次使用
1. 在 Chrome 中使用自己的 BOSS 招聘账号登录，进入沟通页面。
2. 点击 Chrome 工具栏里的“识才”，打开工作台。
3. 在“招聘岗位”中新建正在招聘的岗位，填写岗位名称、JD 和筛选要求。
   岗位名称或别名应与 BOSS 页面显示的沟通岗位对应。
4. 在“模型与设置”中填写公司提供的模型接口地址、模型名称和 API Key，确认资料发送授权后保存。
5. 点击“开启页面扫描”，回到 BOSS 并刷新页面。
6. 打开在线简历后可自动读取；点击“自动读取简历”可依次读取候选人。
   读取过程中保持 BOSS 页面在前台。插件会自动滚动简历、在本机识字，并显示进度。
7. 完整简历会按设置加入分析队列；工作台点击“继续分析”后才运行模型队列。
   可分别暂停简历读取或模型分析。

在线简历内容不足时会标记“已跳过 · 内容不足”，自动读取继续下一位。
聊天中的招呼内容不用于评分。模型输出用于招聘人员复核。

三、数据与模型配置
- 此安装包不包含发送者保存的 API Key、岗位配置、真实候选人记录或 BOSS 登录状态。
- 每位同事需要自行配置岗位和公司分配的模型 Key。
- 岗位、候选人池、收藏和分析结果保存在各自 Chrome 的本机存储中，目前不会在同事之间同步。
- 图片识别组件及中文、英文词库已随包提供，OCR 在本机运行；模型分析会将处理后的简历文本和岗位 JD 发到所填接口，并可能产生 API 费用。
- 这是内部测试版。当前版本通过 123 项自动化测试和构建，尚未在同事电脑上验证；真实模型分析的完整流程仍在排查和验收中。

四、以后更新
1. 停止当前自动读取，暂停分析，等待正在执行的任务结束。
2. 收到新版 ZIP 后解压，用新版 shicai-extension 内的文件替换原安装目录内的文件，保持原目录位置。
3. 在 chrome://extensions 找到“识才”，点击其重新加载按钮。
4. 刷新 BOSS 页面和工作台，核对版本号。此开发版不会自动更新。

Chrome 官方安装说明：
https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked

常见问题：
- “缺少或无法读取清单”：通常选错了文件夹，应该选择直接包含 manifest.json 的 shicai-extension。
- 显示“界面预览”：请从 Chrome 扩展图标进入工作台，不要直接打开 HTML 文件。
- 出现模型异常：打开候选人详情，复制“模型请求状态与错误记录”的完整报错给维护人员，不需要提供 Key。
